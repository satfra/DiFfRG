# Vendored AUMP

This directory contains the minimal runtime from
[keiwanjamaly/AUMP](https://github.com/keiwanjamaly/AUMP) at commit
`a1bbf57b2b375384ae48c4aa20a4be8c0b8c7828`.

The runtime files and `LICENSE` are copied without modification. DiFfRG invokes
`Runner.wls` directly from CMake so test configuration and execution do not
require network access.
